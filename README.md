# Noham Ouazine

16. I build brains for machines.

A language model first, now a neuron on a chip. The goal is a small brain that a robot can carry on a battery.

## What I'm building

| Project | What it is | State |
|---|---|---|
| **Vertigo 3** | A small language model that answers in French. 98 MB, runs in a browser tab, shows its source. [Code](https://github.com/nohamouazine/vertigo), [demo](https://huggingface.co/spaces/nohamouazine/vertigo-3-demo) | Public |
| **Vertigo 4** | The next version, four times larger, learning to hold a conversation and to write code | In training |
| **Spiking neuron** | One neuron in Verilog, on a Tiny Tapeout tile, through Hack Club's chip program [Code](https://github.com/nohamouazine/tt-neurone) | Public |
| **Klein** | A desk robot that will carry this brain. Six 3D-printed parts | Drawn, not built |

I work on [ParadoxalAI](https://paradoxalai.com) with [Reel](https://github.com/Vyn042). We train our own models, on a gaming PC and free cloud GPUs.
